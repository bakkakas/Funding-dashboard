# sUSDe rewards panel

Verified 2026-11-09 against the official Ethena Market Data dashboard and public requests it uses.

- Headline / 30D / 90D: `https://app.ethena.fi/api/yields/protocol-and-staking-yield`, exact fields `stakingYield`, `avg30dSusdeYield`, `avg90dSusdeYield`. Values already in percent, each with its own `lastUpdated` date. Do not replace these with the protocol yield or daily history's last observation.
- History: `https://app.ethena.fi/api/yields/historical/historical-protocol-and-competitor-yields`, exact `queryIndex.name == "sUSDe Yield"`. Do not select `Indicative sUSDe APY`. All 1,039 available daily records were archived through 2026-11-04 at initial delivery.
- Chart: **reconstructed 7-calendar-day arithmetic mean** of source APYs, not cumulative return, not weekly realized return and not an archive of historical headline announcements. Full history is averaged before range clipping. Latest mean must match current official APY within 0.02 percentage points or collection fails closed. No additional annualization/compounding of the already annualized source values.
- Initial values: official APY 5.247142857%, 30D 4.9904%, 90D 4.78517647%, all dated 2026-11-04. Daily history's final value is 7.88%, which is NOT the current official headline APY. Summary averages are published by Ethena, not locally recalculated from daily history.
- Historical source yields include negatives; preserve them, but explain they are not deductions from the staking vault. Missing days are not zero-filled or carried forward. Any missing date invalidates its rolling window and breaks the chart path.
- Rewards are discretionary, not fixed or guaranteed. USDe alone does not earn sUSDe rewards. Revenue is generated by backing assets, not by lending out USDe deposited in the staking vault. Official documentation describes weekly accounting and next-week installment distributions, with weekly compounding for APY. The simplified weekly formula is explanatory, not a replication of internal accounting.
- Model-free local LaunchAgent `com.openclaw.funding-susde-yield` every 6 hours while the host is available; visible panel checks same-origin snapshot every 5 minutes. Source date and fetched date are shown separately. Source >10 days or collection >48h produces a warning; collector rejects >14-day sources, future data, ambiguous source series, inconsistent headline, regression or history deletion. Atomic replacement preserves the last good snapshot on any failure. The independent collector cannot break the existing USDe market-cap collector. GitHub-hosted requests were verified to redirect to `https://ethena.fi/restricted` (runs 42545061382, 42545121520), so the workflow is manual-only; feature-branch probes cannot publish. Local ordinary requests return JSON without proxies or header-based location overrides. Runtime: OpenClaw workspace `automation/susde-yield/run.py`, dedicated clone, advisory process lock and stdout/stderr logs. Install `scripts/run_susde_yield_local.py` there and pass that runtime directory as its argument. Sleeping/offline host delays collection; UI source/fetch timestamps and delay labels remain visible.

## Actual holding returns (2026-11-11)

- Separate panel and `data/susde-returns.json`; official public endpoint `https://app.ethena.fi/api/susde-price-history?range=All`. Valid range strings are case-sensitive (`All`, `1M`, `6M`, `1Y`, `2Y`). Official staking app uses this exact series, `price / initial price`, to compute its hypothetical 1,000-USDe rewards chart (frontend module 449296, price consumer 680950, observed Nov 11). The app separately reads `convertToAssets(1e18)` for current USDe per sUSDe. This is the official app's redemption-rate history, not a DEX USD price; historical block-level RPC values were not independently revalidated.
- `price` is USDe per sUSDe; preserve full numeric source precision and timestamps. Archive latest observation per completed UTC date, usually around 23:00 UTC, excluding today's incomplete observation. These are daily samples, NOT daily averages/midnight closes. Sample timestamps can differ by seconds. 1,093 completed daily observations 2023-11-14–2026-11-10 at delivery; do not call entire available history an individual user's holding return or guarantee inception coverage.
- Actual period growth = `(end rate / start rate - 1) * 100`; no APY averaging/compounding or annualization. N-day return needs endpoints N calendar days apart (N+1 rows when complete). Exact missing endpoints are unavailable, no nearest-date substitution. Missing interior samples break lines but do not invalidate a measurable endpoint return. Preserve zero/negative source changes, never clamp them upward.
- 30D/90D/365D cards, independently rebased cumulative chart (30D/90D/365D/all), custom start date, and hypothetical 10,000-USDe final balance. USDe basis, before gas/fees/slippage/taxes/depegging/FX or post-unstake cooldown. No wallet/account access is needed.
- Return collector rejects malformed/non-positive/nonfinite/future/stale (>3 days) histories and disappearing existing dates. Atomic writes preserve last valid history. Browser also validates schema/dates/unit and retains last good snapshot on refresh failure; >3-day source or >48-hour fetch delay warns.
- Existing six-hour local runner collects APY and returns independently: an APY failure does not prevent a valid rate update and vice versa. Valid snapshots are published; any partial failure remains a nonzero run outcome. Install the updated runner in `automation/susde-yield/run.py`. Existing manual APY GitHub workflow stays APY-only because GitHub's official source access is restricted; it is not the return refresh path.
